# Tugas Kuliah Final Project Data Mining
laporan penelitian dengan metode CRCRISP-DM

judul: Pembuatan Model Prediksi Harga Cabai Merah Besar di pasar Tradisional Jakarta berdasarkan Pengaruh Iklim Cuaca di Daerah Pemasok Bandung

Topik: Smart Economy & Smart Food Security

Timeline berdasarkan metode CRCRISP-DM:
1. Business Understanding (1 minggu)
   - Identifikasi masalah bisnis: Menganalisis faktor-faktor yang mempengaruhi harga cabai merah besar di pasar tradisional Jakarta.
   - Tujuan penelitian: Membangun model prediksi harga cabai merah besar berdasarkan data iklim cuaca di daerah pemasok Bandung.
2. Data Understanding (2 minggu)
   - Pengumpulan data: Mengumpulkan data harga cabai merah besar di pasar tradisional Jakarta dan data iklim cuaca di daerah pemasok Bandung.
   - Eksplorasi data: Melakukan analisis eksplorasi data untuk memahami pola dan hubungan antara variabel-variabel yang ada.
3. Data Preparation (2 minggu)
   - Pembersihan data: Menangani data yang hilang, outliers, dan melakukan transformasi data jika diperlukan.
   - Pemilihan fitur: Memilih fitur-fitur yang relevan untuk model prediksi.
4. Modeling (3 minggu)
   - Pemilihan algoritma: Memilih algoritma machine learning yang sesuai untuk membangun model prediksi harga cabai merah besar.
   - Pelatihan model: Melatih model menggunakan data yang telah dipersiapkan.
5. Evaluation (1 minggu)
   - Evaluasi model: Menggunakan metrik evaluasi yang sesuai untuk menilai kinerja model prediksi.
   - Validasi model: Melakukan validasi silang untuk memastikan model tidak overfitting.
6. Deployment (1 minggu)
   - Implementasi model: Menerapkan model prediksi harga cabai merah besar dalam lingkungan produksi.
   - Monitoring model: Memantau kinerja model secara berkala dan melakukan pembaruan jika diperlukan.
7. Reporting (1 minggu)
   - Penyusunan laporan: Menyusun laporan penelitian yang mencakup semua tahapan CRCRISP-DM dan hasil yang diperoleh.
   - Presentasi hasil: Menyajikan hasil penelitian kepada pemangku kepentingan terkait.
